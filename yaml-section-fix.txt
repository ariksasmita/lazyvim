⏺ Great question! Let me clarify how it works:

  How YAML Folding Works

  <leader>yf> toggles whether YAML folding is enabled for this buffer, not the fold itself.

  The Workflow

  1. Enable YAML folding:
  Press <leader>yf>
  → Notification: "YAML frontmatter fold enabled"
  → The fold capability is now active
  2. Actually fold/unfold the YAML:
  Place cursor on the YAML section and use normal Vim fold commands:
    - za - Toggle fold open/closed
    - zc - Close fold
    - zo - Open fold
    - zR - Open all folds
  3. Disable YAML folding:
  Press <leader>yf> again
  → Notification: "YAML frontmatter fold disabled"
  → YAML section unfolds and won't fold again

  Why Two Steps?

  This design allows markview.nvim to render YAML nicely when folding is disabled, but lets you fold it out of the way when needed.

  Quick Reference

  | Action      | Keybinding    | Description                              |
  |-------------|---------------|------------------------------------------|
  | <leader>yf> | Toggle ON/OFF | Enables/disables YAML folding capability |
  | za          | Toggle fold   | Fold/unfold YAML (when cursor on it)     |
  | zc          | Close         | Fold YAML section                        |
  | zo          | Open          | Unfold YAML section                      |
  | <leader>zR  | Open all      | Unfold everything                        |

  Example Usage

  ---

  tags: test

  1. Press <leader>yf> (enables folding)
